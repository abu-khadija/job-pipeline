# Roadmap after the pipeline (context only, not for the build)

Decisions from the Oct 2, 2026 planning conversation. Main goal: sign the first remote contract.
The bottleneck is the technical interview, not the number of applications.

## Expectations (estimates, not promises)

- Pipeline live by late October. By Dec 31: roughly 300–450 applications, 12–25 recruiter screens,
  5–10 technical rounds, 0–2 offers.
- Offer signed by Dec 31: ~50–60%. Starting before Jan 1: ~15% (30-day notice + December slowdown).
  Most likely start: Jan–Feb 2027.

## Recruiter advice: things only Islam can do (high impact, do them now)

1. **LinkedIn headline** (truthful): "AI-First QA Engineer · Playwright + TypeScript · Remote · Contractor via Deel/EOR".
   Location: Alexandria, Egypt. Turn on **Open to Work → recruiters only**, titles from `config/targeting.yaml`,
   "Remote", job type contract + full-time. Recruiters search "QA Automation Egypt open to remote";
   this can bring more screens than 100 applications.
2. **Referrals tab:** for each row, open the LinkedIn search link, find an Egyptian (or any) engineer there,
   and ask for a referral in your own words. Update `status` (asked / referred / none_found). Never automated.
3. **Gulf market:** set Bayt and Wuzzuf alerts for remote QA roles paid in foreign currency
   (SETUP B3). Arabic + RTL testing is a niche with little competition.
4. **Promptfoo LLM-eval project moved earlier:** start it right after the exam, in parallel with the
   first applications. Type B "testing AI products" roles are often open worldwide and pay the most;
   once the project is public, set `typeB.penaltyEnabled: false`.

## Worth paying for (in order)

1. Mock interviews with a senior SDET/QA (Upwork, ADPList free mentors, Exponent): 3–4 sessions.
2. Public Playwright + TypeScript demo repo against a public demo site (never employer code). Islam
   must be able to explain every line.
3. Daily hand-written TypeScript practice (Exercism; a Playwright course).
4. LinkedIn Premium Career for 2–3 months; InMails written and sent by Islam personally.
5. Personal domain + one-page portfolio (QAX demo video, project links).
6. Claude Max for one month only if Pro limits slow the build.
7. Public LLM eval project with Promptfoo (7–10 days, now planned right after the exam); then set `typeB.penaltyEnabled: false`.

Never pay for "guaranteed job" services, referrals, mass auto-apply tools, or bulk recruiter-email tools.

Turing, Arc.dev, Mercor, Andela, Proxify, Index.dev, Remotebase, Braintrust, Crossover, Toptal, X-Team;
AI-training platforms (Outlier, DataAnnotation, Alignerr, OpenTrain, Invisible); crowdtesting

Check the current employment contract for side-work clauses first.

## After the first offer (not before)

- Hermes Agent as a read-only personal assistant: daily coding drills, opportunity scout, interview
  prep, Sheet brief. No send permission, no passwords.
- Side income, max two at a time: AI evaluation gigs (Arabic + code), crowdtesting, then Arabic/RTL
  localization QA. Later: QA/monitoring for automations, Telegram channel of Egypt-eligible remote
  jobs fed by this pipeline, an n8n learning track.
- Avoid: two full-time jobs in the first 6 months, trading bots, mass AI content, agents acting inside
  platform accounts.
